# AniList 标签简体中文显示表

本项目的 `data/localization/tag-labels.json` 是独立编写的 AniList 标签显示名表。每个有效表项只包含原始标签键（历史参考）`rawName` 和本项目编写的 `displayName`，不包含翻译说明、排名、用户数据或媒体数据。

## 版本与范围

- 格式：`schemaVersion: 1`
- 数据版本：`tag-labels-2026-11-05`
- 有效词条数：426
- 原始键：426 个互不重复的名称
- 覆盖范围：历史参考清单中的 426 个有效键

原始键清单从历史参考材料 按原有顺序提取，仅取英文键，不含该参考仓库的中文译名或描述。它的来源是 [TouhouGO/anilist-zh-cn-userscript 的标签审阅表](https://github.com/TouhouGO/anilist-zh-cn-userscript/blob/05708908c5bcda2fc92898bb87eb5c12025c75bb/data/tag-translation-review.csv)，固定提交为 `05708908c5bcda2fc92898bb87eb5c12025c75bb`，该文件 SHA-256 为 `4142dab70482768d7bc9b5c8c34838d354bcc5c6a5f66c3f620bec7a02edf97e`。

这份清单是历史参考材料，**尚未与 AniList 当前 `MediaTagCollection` 实时核对**。426 项不等于当前标签总数，本表不声明全量、官方或持续覆盖。此次直接请求 AniList GraphQL 返回 Cloudflare HTTP 403（错误 1010，要求不要重试），因此没有取得当前集合。参考仓库的数据权属也没有被完整证明；本项目不把它当作外部中文词典使用。

## 编写与来源边界

显示名由本项目依据英文键名称和通用语义独立编写。没有复制相邻用户脚本、旧聚合词典或其他第三方词典的中文译名；没有抓取或复制标签说明作为译文。表中出现相同中文显示名不代表合并词条，全部 426 个有效原始键仍分别保留。服务端查询、筛选和回退时应使用 `rawName`；`displayName` 仅供界面展示。遇到未收录名称时应保留原名。

本项目没有为这些人工编写标签名称取得或声称第三方中文词典的数据许可。来源清单的许可不确定性不应被表述为已经解决。
